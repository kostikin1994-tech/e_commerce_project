# E-commerce Project

Учебный проект на Python для изучения объектно-ориентированного программирования (ООП).

## Описание проекта

Проект представляет собой базовую модель интернет-магазина. В нём реализованы классы товаров и категорий, наследование, абстрактные классы, миксины, инкапсуляция и магические методы.

## Реализованный функционал

### 1. Абстрактный класс BaseProduct

- Выступает родительским классом для продуктов.
- Содержит общие атрибуты: название, описание, цена и количество.
- Определяет абстрактный метод `__str__`, который должен быть реализован в дочерних классах.

### 2. Класс Product

- Наследуется от `BaseProduct` и миксина `MixinLog`.
- Содержит свойства товара.
- Использует `@property` и setter для контроля изменения цены.
- Реализует магические методы `__str__`, `__add__`.
- Содержит класс-метод `new_product` для создания новых товаров и объединения количества при совпадении названий.

### 3. Класс Category

- Хранит название, описание и список товаров.
- Поддерживает добавление товаров с проверкой их типа.
- Подсчитывает количество категорий и товаров.
- Реализует строковое представление категории.

### 4. Дочерние классы продуктов

- `Smartphone` — смартфоны с дополнительными характеристиками: производительность, модель, память и цвет.
- `LawnGrass` — газонная трава с характеристиками страны-производителя, периода прорастания и цвета.

### 5. Миксин MixinLog

- Выводит информацию о создании объекта.
- Реализует магический метод `__repr__` для представления объекта.

## Тестирование

Для проверки работоспособности проекта используются `pytest` и `pytest-cov`.

В проекте реализованы тесты для проверки:
- Создания товаров и категорий.
- Изменения и проверки цены.
- Добавления товаров в категории.
- Работы наследования и абстрактного класса.
- Работы миксина и магических методов.
- Обработки некорректных данных.

## Запуск проекта

Рекомендуется использовать Python 3.12 или выше.

Создание виртуального окружения:

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.venv\Scripts\activate
```

Установка инструментов тестирования:

```bash
pip install pytest pytest-cov
```

Запуск тестов:

```bash
python -m pytest
```

Запуск тестов с проверкой покрытия кода:

```bash
python -m pytest --cov=src.main --cov-report=term-missing
```
